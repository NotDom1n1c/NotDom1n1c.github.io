Datenschutz

Stand: September 2026

Diese Seite ist eine persönliche Website von Dominic Aebersold. Sie dient ausschliesslich dazu, mich, meine Ausbildung und meine Projekte vorzustellen. Datenschutz ist mir wichtig, darum sammelt diese Seite so wenig Daten wie möglich.

Keine Cookies, kein Tracking

Diese Seite setzt keine Cookies, nutzt kein Analyse-Werkzeug und kein Tracking. Es werden keine Nutzungsprofile erstellt und keine Daten an Werbe- oder Analysedienste weitergegeben. Deshalb gibt es auch kein Cookie-Banner.

Kontaktaufnahme

Auf der Startseite findest du meine E-Mail-Adresse. Wenn du mir schreibst, verarbeite ich die von dir übermittelten Angaben (z. B. Name, E-Mail-Adresse, Inhalt der Nachricht) nur, um deine Anfrage zu beantworten. Ein Kontaktformular gibt es bewusst nicht, damit keine Daten über diese Seite erhoben werden.

Diese Seite wird über GitHub Pages (GitHub, Inc.) bereitgestellt. Beim Aufruf kann GitHub technisch notwendige Zugriffsdaten speichern (z. B. IP-Adresse, Zeitpunkt, aufgerufene Datei). Diese Daten dienen dem sicheren Betrieb der Seite. Mehr dazu im Datenschutzhinweis von GitHub.

Schriftarten

Diese Seite lädt Schriftarten von Google Fonts (fonts.google.com). Dabei kann deine IP-Adresse an Google übermittelt werden. Wenn du das vermeiden willst, können die Schriften später lokal eingebunden werden.
