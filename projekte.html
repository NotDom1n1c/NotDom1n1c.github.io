    Cracked Hub

    Ein komplettes Bedienoberflächen-Framework für Roblox-Skripte, selbst gebaut statt mit einer fertigen Bibliothek. Es liefert Tabs, Abschnitte, Schalter, Schieberegler, Auswahllisten, Textfelder und Tastenkürzel als wiederverwendbare Bausteine, dazu ein Benachrichtigungssystem, einen Weichzeichner-Hintergrund und mehrsprachige Beschriftungen. Einstellungen werden als JSON gespeichert und beim nächsten Start automatisch wieder geladen. 

    save = function(self, file_name, config)
    local success_save, result = pcall(function()
        local flags = HttpService:JSONEncode(config)
        writefile('Cracked - Hub/'..file_name..'.json', flags)
    end)

    if not success_save then
        warn('failed to save config', result)
    end
end

  • PowerShell

    Dateien-Sortierer

    Räumt lose Dateien automatisch in die richtigen Ordner ein. Das Skript liest Modulnummern aus dem Dateinamen und sogar aus dem Inhalt von Word-, PowerPoint- und Excel-Dateien, erkennt Themen wie OSI oder Hyper-V und ordnet sie dem passenden Schulmodul zu. Was nicht eindeutig ist, lässt es bewusst liegen, statt es falsch abzulegen. Jede Verschiebung wird protokolliert und ist rückgängig zu machen. 

    1. Modulnummer im DATEINAMEN  ("Modul_114", "M346")
2. Modulnummer im INHALT      (Doc sagt "ICT Modul 431")
3. Thema in Name ODER Inhalt  ("OSI"/"VPN" -> 117, "Hyper-V" -> 190)
4. Bekannte Dateiendung       (.pdf, .png, .docx ...)
5. Alles andere               -> Sonstiges

    295 Zeilen · mit Rückgängig-Protokoll
