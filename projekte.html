    Makro-Rekorder

    Eigenes Windows-Programm, das Mausbewegungen, Klicks, Mausrad und Tastatur aufnimmt und wieder abspielt, auf Wunsch auch endlos. Es hängt sich über systemweite Low-Level-Hooks in Windows ein und spielt die Eingaben mit SendInput wieder ab. Mit F9, F10 und Esc lässt es sich aus jedem Fenster steuern, ohne dass diese Tasten in der Aufnahme landen. Tempo, Anzahl Durchläufe und Pausen sind einstellbar, Aufnahmen werden als Textdatei gespeichert und wieder geladen. 

    // Steuertasten abfangen, damit sie nicht in der Aufnahme landen
if (vk == (int)Keys.F9)
{
    if (down) BeginInvoke(new MethodInvoker(ToggleRecord));
    return new IntPtr(1);
}
if (vk == (int)Keys.Escape && playing)
{
    stopRequested = true;
    return new IntPtr(1);
}
if (recording) Add(down ? Ev.KDOWN : Ev.KUP, 0, 0, vk);

    Dateien-Sortierer

    Räumt lose Dateien automatisch in die richtigen Ordner ein. Das Skript liest Modulnummern aus dem Dateinamen und sogar aus dem Inhalt von Word-, PowerPoint- und Excel-Dateien, erkennt Themen wie OSI oder Hyper-V und ordnet sie dem passenden Schulmodul zu. Was nicht eindeutig ist, lässt es bewusst liegen, statt es falsch abzulegen. Jede Verschiebung wird protokolliert und ist rückgängig zu machen. 

    1. Modulnummer im DATEINAMEN  ("Modul_114", "M346")
2. Modulnummer im INHALT      (Doc sagt "ICT Modul 431")
3. Thema in Name ODER Inhalt  ("OSI"/"VPN" -> 117, "Hyper-V" -> 190)
4. Bekannte Dateiendung       (.pdf, .png, .docx ...)
5. Alles andere               -> Sonstiges
